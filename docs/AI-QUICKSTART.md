# AI로 청주시의회 회의록 사용하기

의원 발언을 찾거나, 여러 의원의 질의를 비교하거나, 담당 부서의 예상질의를 준비할 때 사용할 수 있습니다. 정식 공개본과 임시회의록을 함께 조회하며 임시본은 구분해 표시합니다.

## 가장 간단한 시작

파일 검색·터미널 실행이 가능한 AI 에이전트에 다음 문장을 그대로 전달하세요.

> https://github.com/nankjh0110/cheongju-council-minutes 의 cheongju-council-minutes 스킬을 설치하고 사용해 주세요. 회의록 자료가 없다면 공개 저장소를 작업 폴더에 복제해 주세요. 수집 기준일을 확인한 뒤, 2024~2026년 공원관리과 관련 발언을 찾아 의원별 주요 쟁점과 예상질의를 정리해 주세요. 원문 근거 링크를 붙이고 실제 발언과 예상을 구분해 주세요.

AI 도구의 실행·네트워크 권한이 필요합니다. 일반 웹 대화에 링크만 붙이는 것으로 전체 회의록 검색 도구가 설치되지는 않습니다. 실행이 불가능한 대화 환경에서는 아래처럼 이용하세요.

1. 저장소의 [연도별 목록](../indexes/years/README.md)에서 관련 회의록을 엽니다.
2. Markdown 파일을 내려받아 대화에 첨부합니다.
3. “첨부한 회의록 범위에서만 예상질의를 작성하고, 회의일과 발언자를 붙여 주세요”라고 요청합니다.

## 스킬 설치 명령

Node.js와 Git이 있는 환경에서 [skills CLI](https://github.com/vercel-labs/skills)의 다음 명령으로 설치할 수 있습니다. 설치 과정에서 사용 중인 에이전트를 선택하세요.

```bash
npx skills add nankjh0110/cheongju-council-minutes --skill cheongju-council-minutes
```

배포된 작은 ZIP은 [Releases](https://github.com/nankjh0110/cheongju-council-minutes/releases)에서 받을 수 있습니다. 압축을 풀면 `cheongju-council-minutes/SKILL.md`와 검색 도구가 있습니다. 사용하는 에이전트가 안내하는 스킬 폴더에 이 폴더를 넣으세요. ZIP을 모든 AI 채팅창에 올리면 자동 설치되는 방식은 아닙니다.

스킬에는 전체 회의록을 넣지 않았습니다. 최초 사용 시 에이전트가 공개 자료 저장소를 복제해야 합니다. 검색은 Python 3.10 이상, 외부 패키지 없이 실행됩니다. 별도 API 키를 요구하지 않지만 사용하는 AI 서비스의 요금·사용량은 해당 서비스에 따릅니다.

## 이렇게 물어보세요

> 2024·2025·2026년 회의록에서 어린이 물놀이장 관련 발언을 모두 찾아 주세요. 의원별 질문과 담당자의 답변을 구분하고 원문을 연결해 주세요.

> 김준석 의원의 공원 관련 발언을 기간별로 살펴보고 반복된 지적과 과거 답변 약속을 정리해 주세요. 이행 여부가 확인되지 않으면 확인 필요로 표시해 주세요.

> 내가 선택한 여러 의원의 발언을 비교해서 공원관리과에 나올 법한 예상질의를 만들어 주세요. 의원 이름은 먼저 수집 명단에서 확인해 주세요. 각 질문마다 왜 예상하는지와 준비할 자료를 알려 주세요.

> 이번 분석에서 실제로 읽은 회의록 수와 기간을 알려 주세요. 아직 읽지 않은 결과가 있다면 이어서 확인해 주세요.

## 업데이트

공개 자료는 GitHub에서 매일 자동 갱신됩니다. 내 컴퓨터의 자료는 별도 갱신이 필요하므로 AI에게 “자료 저장소를 최신화한 뒤 분석해 주세요”라고 요청하세요. 스킬의 지침·검색 도구를 업데이트하려면 설치 명령을 다시 실행하거나 새 ZIP으로 교체합니다. 개인 수정본은 먼저 보관하세요.

## 제공 범위

이번 배포는 **에이전트 스킬과 로컬 읽기 전용 검색 도구**입니다. 상시 실행 서버나 원격 MCP 주소는 제공하지 않습니다. 저장소·설치·원문 열람에는 API 키가 필요하지 않습니다. 예상질의 문장은 사용자가 이용하는 AI가 작성합니다.

검색 도구는 여러 의원·연도·위원회 조건, 의원 전체 발언 열람, 페이지 이동, SHA-256 원문 검사, 원문 줄 링크를 지원합니다. 회의록에 나타나지 않은 현재 관심사나 미래 발언을 사실로 단정하지 않습니다. 과거 발언이 부족한 의원은 자료 부족을 표시합니다. 청주시의회 공식 서비스가 아닌 공개 자료 활용 도구입니다.

배포 구조는 [Legalize-KR Agent Skills](https://github.com/legalize-kr/agent-skills)를 참고했습니다. 해당 저장소의 코드나 문구를 복사하지 않았습니다.
